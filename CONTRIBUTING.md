# Project Contribution Information

**Desolate Planet** is a hardcore survival Minecraft modpack on Forge 1.20.1, inspired by the Crash Landing modpack for 1.6.4. Mod files and distribution is handled by [Packwiz](https://packwiz.infra.link/).

If needed, see the [`README.md`](README.md) file for more descriptive information about the modpack. Other player-facing information should be visible If required, further information shown to the player includes the tips at `packwiz-scripts/tip_generation/tips.csv`, the item tooltips at `kubejs/client_scripts/tutorial_tooltips.js`, or all the quests and their descriptions at `config/hqm/default/sets/`.

## Folder Structure

The root of this repository is intended to be used as a **live** game directory. See below for information about how to automatically download mods and initialize a local development environment. Below is a list of the most relevant folders and files in the modpack.

- `config/` - Client and server mod config files
  - `hqm/` - Stores the modpack's quests in JSON format. It is safe to manually edit these for small tweaks, but all large-scale changes should be done in the ingame editor.
  - `openloader/` - Stores most of the data/resource pack files for the modpack:
    - `data/` - Datapack files, including recipes, structures, loot tables, and other data-based mod options. Reloaded with /reload or world relaunch.
    - `resources/` - Resource pack files, including custom textures, models, and language files.
- `defaultconfigs/` - Server-only default configs (applied on first server launch). Config files can be copied from a world's `serverconfig` folder into this folder to preset them. Server config files not present here will use default values.
- `kubejs/` - KubeJS scripting handles most custom content and recipe modification:
  - `assets/` - Custom textures, lang files, and tip JSONs for the in-game tutorial system.
  - `client_scripts/` - Mostly JEI integration (hiding items) and tooltip additions (runs at client load, reloaded with `/kubejs reload client_scripts`).
  - `config/` - Config files for KubeJS itself.
  - `data/` - Datapack files that more specifically pertain to the custom content in the modpack.
  - `probe/` - Auto-generated files for VS Code auto-complete. This folder is not comitted by default and must be generated by downloading the ProbeJS mod and running `/probejs dump`.
  - `server_scripts/` - Recipe additions/removals and server-side events (runs at world load, reloaded with `/reload`).
  - `startup_scripts/` - Registers custom items, blocks, and fluids (runs at game startup, only reloaded by relaunching the game).
- `packwiz-builds/` - Exported builds of the modpack
- `packwiz-curseforge/` - CurseForge pack files (references mods by CurseForge ID, the `pack.toml` file configures modpack info and version numbers, other files are edited only by packwiz commands).
- `packwiz-modrinth/` - Modrinth pack files (references mods by Modrinth ID, the `pack.toml` file configures modpack info and version numbers, other files are edited only by packwiz commands).
- `packwiz-scripts/` - Contains scripts for editing the modpack, including exporting builds:
  - `configs/` - Contains configs for other scripts, including a list of files copied into the client and server builds upon export.
  - `nbt_conversion/` - Contains tools for converting between nbt and snbt files, allowing structure NBT files (`/config/openloader/data/dustplanet/data/desolate_planet/structures`) to be edited in text form before being switched back.
  - `tip_generation/` - Tools related to making tips, shown on loading screens. Tips are in the `tips.csv` file, and are converted into user-accessible format by running `generate_tips.py` and copying the generated tip files into `kubejs/assets/desolate_planet/tips` and the generated translation files into `kubejs/assets/tips/lang`.
  - `tools/` - Stores any temporary files the other scripts need to use, including the Forge jars.
- `packwiz-server/` - Server pack (contains auto-generated server launch files, a preset world, and copies of pack files created by running the associated script)
- `profileImage/` - Contains media files and promotional images for the modpack.

## Packwiz Modpack Management (Windows)

### Prerequisites

- Java (for the packwiz installer bootstrap and Forge installer)
- A local copy of this repository

### Local Environment Setup

1. Install **packwiz** by following the official guide: [https://packwiz.infra.link/installation](https://packwiz.infra.link/installation/). Ensure packwiz is added to your PATH.
2. Run the `initialize-dev-environment.bat` script located in the `packwiz-scripts` folder. The script will download all required files.
3. [Install Forge 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)**.**
4. In the Minecraft Launcher, create a new installation.
    1. Set the version to the appropriate Forge version.
    2. Set the game directory to your repository's directory.
    3. Under JVM arguments, increase your allocated RAM to 6-8GB (change `-Xmx2G` to `-Xmx6G` or `-Xmx8G`).
    4. Save the installation.
5. Select the new installation and click **Play**.

### Mod List Changes

All mod changes must be done via packwiz commands, and **must be made on both pack variants**.

**Add a mod:**

```bash
packwiz modrinth add <url|slug|search> --pack-file ".\packwiz-modrinth\pack.toml"
packwiz curseforge add <url|slug|search> --pack-file ".\packwiz-curseforge\pack.toml"
```

**Remove a mod:**

```bash
packwiz remove <name> --pack-file ".\packwiz-modrinth\pack.toml"
packwiz remove <name> --pack-file ".\packwiz-curseforge\pack.toml"
```

**Update a mod:**

```bash
packwiz update <name> --pack-file ".\packwiz-modrinth\pack.toml"
packwiz update <name> --pack-file ".\packwiz-curseforge\pack.toml"
```

**Update all mods** (*before confirming, ensure the version numbers and modlist match*):

```bash
packwiz update <name> --pack-file ".\packwiz-modrinth\pack.toml"
packwiz update <name> --pack-file ".\packwiz-curseforge\pack.toml"
```

After the modlist is changed, run `packwiz-scripts\initialize-dev-environment.bat` to download all mods into the repo root.

### Exporting the Modpack

Build scripts automatically generate distributable modpack files. They copy relevant folders (listed in `packwiz-scripts/configs/client-copy-list.txt`) into the pack directory, run the Packwiz export, then clean up. All exported files are saved to `packwiz-builds/`.

- To **Modrinth:** run `packwiz_scripts\pack-export-modrinth.bat`.
- To **CurseForge:** run `packwiz_scripts\pack-export-curseforge.bat`.
- To **Server Pack:** run, in order:
    1. `packwiz_scripts\pack-export-server-1-forge.bat` (Downloads forge to the packwiz-server directory.)
    2. `packwiz_scripts\pack-export-server-2-mods.bat` (Downloads all mods from the other packwiz folders to the packwiz-server directory.)
    3. `packwiz_scripts\pack-export-server-3-export-curseforge.bat` (Copies required content from the root folder and creates a zip file of all mods and configs.)
    4. `packwiz_scripts\pack-export-server-3-export-modrinth.bat` (Optional, creates a version of the server pack with Modrinth files. Since Modrinth does not allow server pack uploads anymore, this is not necessary.)

All exported modpack files are saved to to `packwiz-builds/`.

## Packwiz Modpack Management (Linux/MacOS)

### Prerequisites

- Java (for the packwiz installer bootstrap and Forge installer)
- A local copy of this repository

### Local Environment Setup

1. Install **packwiz** by following the official guide: [https://packwiz.infra.link/installation](https://packwiz.infra.link/installation/).
2. Serve the Modrinth variant from `packwiz-modrinth/`:
    
    `cd ./packwiz-modrinth && packwiz serve -p 8080`
    
3. Download the [packwiz installer bootstrapper](https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest/download/packwiz-installer-bootstrap.jar) and run it:
    
    `java -jar packwiz-installer-bootstrap.jar http://localhost:8080/pack.toml`
    
    *See the official [tutorial for the packwiz-installer](https://packwiz.infra.link/tutorials/installing/packwiz-installer/) for more information.*
    
4. [Install Forge 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html).
5. In the Minecraft Launcher, create a new installation.
    1. Set the version to the appropriate Forge version.
    2. Set the game directory to your repository's directory.
    3. Under JVM arguments, increase your allocated RAM to 6-8GB (change `-Xmx2G` to `-Xmx6G` or `-Xmx8G`).
    4. Save the installation.
6. Select the new installation and click **Play**.

### Mod List Changes

> *See the Windows instructions above.*

### Exporting the Modpack

The Windows scripts automatically copy the relevant folders and export the modpack. To export on macOS / Linux, you will have to manually perform the tasks the scripts do.

- To **Modrinth:**
    1. Copy the relevant folders and files from the root folder into `packwiz-modrinth/`. You can find the default list of files in `packwiz-scripts/configs/client-copy-list`.
    2. Run `packwiz modrinth export --pack-file "./packwiz-modrinth/pack.toml"`.
    3. Remove the temporary files copied into `packwiz-modrinth/`.
- To **CurseForge:**
    1. Copy the relevant folders and files from the root folder into `packwiz-curseforge/`. You can find the default list of files in `packwiz-scripts/configs/client-copy-list`.
    2. Run `packwiz curseforge export --pack-file "./packwiz-curseforge/pack.toml"`.
    3. Remove the temporary files copied into `packwiz-curseforge/`.
